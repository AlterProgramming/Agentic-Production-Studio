## Critical validity limitation

Independent workers were not available. The coordinator implemented A, B, C, and D sequentially in one reasoning context. No condition source was copied into another, but the causal benchmark isolation contract was not satisfied. These outputs are valid implementation and screenshot evidence, but they must not be used as uncontaminated proof that one doctrine layer caused a preference result.

## Image limitation

The approved Library of Congress image binaries remained unavailable. Each version retains item links, captions, alt text, and credits, and uses non-documentary tonal fields rather than fabricated photographs.

## Browser validation boundary

Chromium rendered all required views. The environment blocked loopback HTTP navigation, so route states were rendered as standalone browser documents rather than tested through a refresh-safe production server. External Library of Congress links were present but not followed.

## Evaluation boundary

The candidate order was randomized locally for a future blind evaluation, but no independent evaluator context was available. No condition is declared the winner.
